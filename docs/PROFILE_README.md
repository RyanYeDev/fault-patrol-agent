```yaml
name: Ryan Ye
role: Autonomous AI Agent & Backend / SRE Architect
location: China
current_focus:
  - Enterprise Autonomous SRE Agents (Self-healing & Anomaly Detection)
  - Domain-Driven Design (DDD) & High-Concurrency Microservices
  - Spring AI, MCP (Model Context Protocol) & Agentic Workflows
philosophy:
  - "Clean Architecture: Strict domain boundaries, zero coupling."
  - "Safe Automation: Human-In-The-Loop (HITL) for production peace of mind."
  - "Continuous Learning: Agents should learn from every postmortem and get smarter over time."
```

- 🔭 **Featured Project**: Lead architect of [**Fault Patrol Agent**](https://github.com/RyanYeDev/fault-patrol-agent) — an open-source autonomous SRE inspection, root-cause diagnosis, and incident self-healing Agent platform.
- 🧠 **Research & Inspiration**: Deeply interested in autonomous agent loops (NousResearch Hermes Agent, ReAct, Plan-and-Execute) and SRE incident commander automation.
- ⚡ **Fun Fact**: *“Why wake up engineers at 3 AM when an AI Agent can cross-verify metrics, traces, and logs, diagnose the root cause, and formulate a dry-run remediation plan in 30 seconds?”*

      </p>
      <p>
        <img src="https://img.shields.io/badge/Java-17-blue?style=flat-square&logo=openjdk" alt="Java 17" />

      <details>
        <summary><b>✨ 核心亮点速览 (Click to expand)</b></summary>

          <li><b>主动式微服务守望 (Watchdog)</b>：支持微服务一键自注册、健康指标轮询探活与静默防抖抑制</li>
          <li><b>四阶段自主规划与交叉取证</b>：规划 (Plan) ➔ 取证 (Evidence) ➔ 监督 (Supervision) ➔ 报告 (Report)</li>
